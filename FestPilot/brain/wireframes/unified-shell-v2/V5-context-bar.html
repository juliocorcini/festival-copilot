Barra de contexto idêntica (morphing)

As duas telas têm o mesmo esqueleto byte a byte: eyebrow → uma "barra de contexto" (mesmo formato/altura) que transmuta entre dias (TT) e busca (LU) → linha de controles que transmuta entre controles e filtros → switch embaixo. Só o conteúdo dentro dos mesmos slots muda.
