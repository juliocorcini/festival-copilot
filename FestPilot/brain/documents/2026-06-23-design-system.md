# FestPilot — Design System (Amber Glass)

> Created 2026-06-23, after the 8-batch design pass (prototypes `#15e`, `#17–#30` in `brain/wireframes/directions/`).
> **Purpose:** the single reference the build implements against — tokens + components extracted from the approved
> Amber Glass prototypes, concrete enough to translate 1:1 into `web/src/styles.css` + React components.
> **Companions:** visual rules in `2026-06-23-ui-decisions-locked.md`; every screen in `2026-06-23-screen-catalog.md`;
> identity rationale in `2026-06-23-ui-dna-and-directions.md`.
> **Rule of thumb:** if a prototype and this doc disagree, this doc wins for *tokens*; the prototype wins for *layout*.

---

## 0. Principles (carry into every component)

- **Amber Glass** (DEC-025): warm dark base, amber/gold accent (~10% of surface, never wallpaper), heavy *reflective*
  frosted glass (diagonal sheen + rim, not flat tint).
- **Never look "AI-made"** — no neon purple/pink/green, no Inter/DM Sans. Oswald (poster titles) + Albert Sans (body).
- **Hard constraints** (DEC, §8 of ui-decisions): sun-legible (high contrast), one-hand (primary actions in lower half),
  battery (dark default), WCAG AA, **scrollbars hidden globally**, bilingual EN/PT (EN default — DEC-039 Q-K).

## 2. Typography

- **Poster / titles:** `Oswald` 500/700, `text-transform:uppercase; letter-spacing:-.01em` → class `.poster`.
- **Body / UI:** `Albert Sans` 400–800.
- **Icons:** `Material Symbols Rounded` (opsz 24, wght 400) → class `.ms`. Filled variants via `font-variation-settings`.
- **Scale (observed in prototypes):** hero 30–34px, screen title 19–26px, section 14–16px, body 13–14px,
  meta/caption 11–12px, micro-label 10–11px. Labels use `.label` (11px, `letter-spacing:.12–.14em`, uppercase, muted).

---

## 3. Shape, spacing, elevation

- **Radii:** cards/sheets 16–20px; pills/buttons 11–16px; phone frame 44px; avatars 50%; admin window 16px.
- **Spacing:** 4-pt-ish rhythm; screen gutters 20–28px; card padding 12–16px.
- **Elevation:** the phone uses `box-shadow:0 50px 100px -30px rgba(245,166,35,.25)` (amber glow). Inner depth comes
  from the glass recipe, not hard shadows.

---

## 4. Glass recipe (the signature)

```css
.glass{
  background:linear-gradient(160deg,rgba(255,255,255,.06),rgba(255,255,255,.015)),rgba(20,17,12,.5);
  border:1px solid var(--border);
  border-radius:20px;
  backdrop-filter:blur(18px);-webkit-backdrop-filter:blur(18px);
}
```
- The diagonal white gradient = the **sheen**; the border = the **rim**. Must read reflective, not "90s flat tint"
  (explicit Julio note in DEC-025). Accent surfaces add `linear-gradient(135deg,rgba(245,166,35,.16),rgba(255,208,96,.03))`
  + `border-color:rgba(245,166,35,.4)`.

## 5. Components (canonical classes)

All exist in the prototypes; reuse names when porting to React/CSS.

**App chrome**
- `.phone` 390×844 frame · `.statusbar` (time + signal/battery) · `.scr`/`.body` scroll regions.
- **Bottom nav `.nav` / `.navitem`** — exactly **5 tabs: Now · Timetable · My Plan · Map · Squad** (DEC-032).
  Active = `--accent`. **Lineup is NOT a tab** (header icon on Timetable). Some pushed screens (settings/profile)
  show **no** bottom nav (modal/stack), reached from a header avatar.

**Actions**
- `.btn` + `.btn-primary` (amber→gold gradient, dark text) · `.btn-ghost` (glass) · `.btn-danger` (red tint) ·
  `.btn-white` (Google/system sign-in) · `.btn-help` (teal, safety).

**Inputs & selection**
- `.field` (text inputs) · `.seg` (segmented control; on-pill = amber gradient) · `.chip`/`.chip.on` (filters, time
  options) · `.toggle`/`.toggle.on` (switches) · radio rows via `radio_button_checked/unchecked` glyphs.

**Data / status**
- `.pill` (status badges; variants: follow=amber, own=blue, warn/danger=red, ok=green) · `.dot` (stage color dot) ·
  `.ava` (avatar: image OR initials + color) · `.tally` (group plurality bar) · `.divider`.

**Surfaces & states**
- `.sheet` + `.grip` (bottom sheet — used for splits, meeting create, precise-sharing control, POI detail, routing) ·
  `.shimmer` (skeleton loading) · empty/error blocks (icon + line + single CTA) · `.push` (notification card) +
  `.lock` (lock-screen background) for OS push.

**Map**
- `.maptile` (illustrated base; grid overlay in admin) · `.mpin` (round friend pin, initials) ·
  `.meetpin`/`.poi` (teardrop pins) · `.stagelbl` (stage label chip) · `.live` (pulsing ring for precise-sharers) ·
  route = inline `<svg><polyline/>` in `--accent`. Live overlay is a **separate vector layer** over the SVG art
  (DEC-030/034) positioned via the affine transform — never baked into the illustration.

**Admin (desktop, B8)**
- `.win` (browser window) + `.chrome` (traffic lights + url) · `.admin` = `.side` (sidebar nav) + `.main` ·
  `.navi`/`.navi.on` (sidebar items) · `.card` · tables (`th`/`td`) · `.matrix` (editable travel-time grid) ·
  `.adminmap` + `.spin` (draggable stage pin) + `.anchor` (affine control point).

## 6. Motion

- Base: natural/spring, **moderate**; gamified/celebratory at Lock in + reunions (DEC-025 / ui-dna).
- `live` ring pulse (presence): scale .85→1.5, opacity .6→0, 1.8s infinite.
- `shimmer`: 1.4s background sweep for skeletons.
- Celebrations (Lock in #13, "everyone's here" B4#4): one-shot burst, skippable.

---

## 7. Accessibility & field-readiness

- **Contrast:** AA minimum; amber-on-dark and ink-on-dark verified; light mode for direct sun.
- **One-hand:** primary CTA + sheets anchored to the **lower half**; back/secondary up top.
- **Battery:** dark by default; map = foreground GPS + significant-move + open (never constant GPS).
- **Scrollbars hidden** everywhere (`::-webkit-scrollbar{display:none}` + `scrollbar-width:none`).
- **i18n:** all copy localizable; **EN default**, PT switchable in Settings (DEC-039 Q-K). Avatar fallback = initials.
